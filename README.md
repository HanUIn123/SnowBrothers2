## ■ 개요
- Windows API를 활용한 2D 게임 모작 프로젝트
- 오락실 게임 '스노우브라더스2'를 모티브로 구현

## ■ 개발 환경
- 언어: C++
- 개발 도구: Visual Studio 2022, Windows API
- 개발 인원: 1 명
- 개발 기간: 2024.06 ~ 2024.07
